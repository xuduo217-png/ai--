# 宠物医院项目功能列表

更新时间：2026-05-29

本文档基于当前仓库源码整理，覆盖移动端 `rnapp`、管理后台 `admin`、后端服务 `server` 已接入或已预留的主要功能。主要参考来源包括移动端路由 `rnapp/src/navigation/AppNavigator.tsx`、移动端 API 统一导出 `rnapp/src/services/api/index.ts`、管理端路由 `admin/src/router/index.ts`、后端模块入口 `server/src/app.module.ts` 以及各业务 controller。

## 一、项目整体组成

### 1. 移动端应用 rnapp

- 技术栈：React Native 0.83、新架构、Fabric、Hermes、TypeScript。
- 支持身份：普通用户端、医生端。
- 核心入口：
  - 首次启动隐私协议确认。
  - 登录态检查。
  - 根据用户类型进入普通用户首页或医生首页。
- 用户端底部主导航：
  - 医疗。
  - 商城。
  - 消息。
  - 好友。
  - 我的。
- 医生端独立首页和咨询工作流。

### 2. 管理后台 admin

- 技术栈：Vue 3、Vite、TypeScript、Element Plus、Pinia。
- 定位：平台运营管理后台。
- 主要模块：医院、医生、用户、宠物、在线医疗、AI 问诊、商品、订单、健康知识、急救指南、好友、善行计划、社区、系统配置、物流等。

### 3. 后端服务 server

- 技术栈：NestJS、TypeORM、MySQL、Redis、Socket.IO、Bull 队列、JWT、Swagger。
- 主要能力：
  - REST API。
  - WebSocket 聊天。
  - 文件上传。
  - 支付与支付回调。
  - 短信验证码。
  - 定时任务。
  - 审计日志。
  - 数据种子脚本。

## 五、当前可见的开发占位与注意事项

- 移动端部分路由仅在 `__DEV__` 下以占位页面注册，包括：
  - 宠物详情 `PetDetail`。
  - 医院列表 `HospitalList`。
  - 医院详情 `HospitalDetail`。
  - 预约列表、创建、详情。
  - 普通个人中心 `Profile`、`Settings`。
  - 医生端咨询详情、收入页、排班、个人中心、设置。
- 后端已经存在对应业务模块或部分接口，但移动端页面尚未完全实现的功能需要以实际页面代码为准。
- `admin/README.md` 仍是后台模板原始说明，不能代表当前业务功能。
- 移动端 `rnapp/README.md` 仍是 React Native 初始化模板说明，不能代表当前业务功能。
- 旧版商城接口路径和新版 `/shop` 接口在移动端服务层中并存，后续可以统一接口命名与文档。
